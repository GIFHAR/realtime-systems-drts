Code, input files, and output files

Contents

code/
  drts_scheduler/      Python package for RM, DM, and EDF analysis/simulation
  tests_project1.py    Regression tests
  requirements.txt     Dependency note

input/
  data/                Local task sets and selected schedulable GitHub cases
  not_schedulable/     GitHub validation cases that are not schedulable by RM

output/
  results/             CSV outputs generated by the experiment runner

How to run

From the extracted ZIP root:

  cd mini-project-1/code
  PYTHONPATH=. python3 -m unittest tests_project1.py
  PYTHONPATH=. python3 -m drts_scheduler.cli ../input/data/example_basic.csv --policy dm
  PYTHONPATH=. python3 -m drts_scheduler.experiment ../input/data --output ../output/results/local_summary.csv

The tool reads CSV task sets, computes WCRT/schedulability results for fixed
priority and EDF policies, and can run deterministic and stochastic
simulations for validation.
