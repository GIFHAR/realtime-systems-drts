Code, input files, and output files

Contents

code/
  tsn_project2/        Python package for TSN CBS/SP analysis and simulation
  tests_project2.py    Regression tests

input/
  examples/            GitHub TSN example test cases used for validation

output/
  results_project2/    CSV outputs generated by the experiment runner

How to run

From the extracted ZIP root:

  cd mini-project-2/code
  PYTHONPATH=. python3 -m unittest tests_project2.py
  PYTHONPATH=. python3 -m tsn_project2.cli ../input/examples/test_case_1
  PYTHONPATH=. python3 -m tsn_project2.experiment ../input/examples --output ../output/results_project2/github_examples_summary.csv

The tool reads topology, stream, and route JSON files, computes link-aware CBS
worst-case delay bounds for AVB streams, compares against a strict-priority
baseline, and simulates CBS/SP behavior with critical-instant and staggered
release patterns.
